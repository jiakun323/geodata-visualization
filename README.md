# Biometric Geo-Visualization

> An interactive Mapbox-based research demo that integrates timestamped GPS trajectories with physiological measurements, event annotations, street-view images, and frequency-spectrum visualizations.

**Live Demo:** https://jiakun323.github.io/geodata-visualization/  
**Repository:** https://github.com/jiakun323/geodata-visualization

---

## English Version

### Project Overview

This project presents continuous physiological measurements through interactive 3D pillars positioned along a geographic trajectory. It is designed to support exploratory analysis of the relationships among physiological responses, spatial context, temporal events, and associated visual data.

Users can:

- switch between multiple physiological indicators;
- compare records through pillar height and colour;
- select individual pillars to inspect timestamps, coordinates, event annotations, and exact values;
- view street-view images associated with specific timestamps;
- examine the corresponding frequency-spectrum visualizations.

### Research Use

This repository is intended primarily for research demonstration, academic communication, and data-visualization exploration. The current version visualizes an existing dataset and should not be interpreted as a clinical, diagnostic, or real-time monitoring system.

For research collaboration, data reuse, redistribution, or adaptation of the project, please contact the author in advance.

## 中文版本

### 项目概述

本项目通过沿地理轨迹分布的交互式 3D 柱体，对连续采集的生理数据进行可视化呈现。该系统旨在支持对生理反应、空间环境、时间事件及相关视觉数据之间关系的探索性分析。

使用者可以：

- 在多个生理指标之间切换；
- 通过柱体高度与颜色比较不同记录；
- 点击单个柱体查看时间、坐标、事件标注及精确数值；
- 查看与特定时间戳对应的街景图像；
- 查看相应的频谱可视化结果。

### 研究用途

本仓库主要用于研究演示、学术交流与数据可视化探索。当前版本基于既有数据集进行可视化展示，不应被视为临床诊断、健康评估或实时监测系统。

如需开展研究合作、复用或传播数据，或对本项目进行二次开发，请提前联系作者。

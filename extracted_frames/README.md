# Street-view images

Copy the JPG files referenced by the GeoJSON into this directory.

Expected path format:

```text
extracted_frames/YYYY-MM-DD_HH-MM-SS.jpg
```

Example:

```text
extracted_frames/2026-07-17_12-56-16.jpg
```

GitHub Pages is case-sensitive. The filename, timestamp, and extension must match the
GeoJSON `image` property exactly.
